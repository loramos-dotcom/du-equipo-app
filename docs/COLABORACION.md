# Cambios desde otra computadora

1. Aceptar la invitación como colaborador en GitHub.
2. Instalar Codex, Git y Node según .nvmrc. Ingresar con cuentas propias.
3. Clonar `https://github.com/loramos-dotcom/du-equipo-app.git` y abrir su carpeta en Codex.
4. Pedir el cambio a Codex. Indicar que primero actualice main y conserve la identidad propia de GitHub.
5. Comprobar las pruebas y subir el cambio a main. Vercel publica la rama conectada automáticamente.

Si otra persona subió cambios mientras se trabajaba, integrarlos antes de publicar y resolver conflictos. No usar push --force sobre main. El código es público; los datos y las credenciales institucionales no pertenecen al repositorio.

La colaboración gratuita de Vercel admite repositorios públicos: https://vercel.com/docs/deployments/troubleshoot-project-collaboration

Este repositorio es la fuente activa de https://du-equipo.vercel.app. El repositorio privado anterior se conserva como respaldo. Quienes tenían una copia del anterior deben clonar este repositorio nuevo; no subir aquí el historial privado ni unir ambos historiales con Git.
